LiveContainer で更新 Release ページ(手動で入れる場合)

  1. Kioku を終了してから押してください(Kioku は LiveContainer の中で動くので、開いたままだと LiveContainer が受け取れません)。アプリ内の「LiveContainer で更新」から来た場合は自動で終了しています。
  2. 「LiveContainer で更新」を押す → LiveContainer が開く → 「既にあるアプリを置き換える」を選ぶ
  3. 一覧の Kioku を起動。画面下の版番号が新しくなっていれば完了
